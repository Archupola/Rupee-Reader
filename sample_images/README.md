# sample_images/

Held-out synthetic demo cards (`sample_demo_<denomination>.png`), created by
`python setup_demo.py` using different random seeds than the training set —
so classifying them is a real (if easy) test, not memorization.

The app's **Demo samples** tab reads this folder. You can also drop your own
test photos here.

Generated files are gitignored; regenerate with `python setup_demo.py`.
